# 🏥 의료기기 백업 현황 대시보드 (Medical Equipment Backup Status Dashboard)

인하대병원 의용공학팀에서 제작한 **의료기기 백업 현황 대시보드**는 병원 내 의료장비의 관리 대상 및 백업(Backup) 진행 현황을 실시간으로 모니터링하고 분석할 수 있는 Streamlit 기반의 웹 애플리케이션입니다.

---

## 🎯 앱의 용도 및 목적

병원 내 의료기기는 환자의 안전과 직결되므로 정기적인 점검, 예방 정비(PM), 보증 및 임대 관리, 그리고 비상 상황에 대비한 백업 체계가 매우 중요합니다. 
본 대시보드는 엑셀 형태로 관리되는 복잡한 의료기기 현황 데이터를 자동으로 파싱하고 시각화하여, 관리자가 백업 대상 장비의 이행 현황을 한눈에 파악하고 부서별·상태별로 신속하게 조회할 수 있도록 돕습니다.

---

## ✨ 주요 기능

1. **자동 파일 탐색 및 기준일 파싱**
   - 디렉토리 내 최신 `의료기기 현황조회_*.xlsx` 파일을 자동으로 탐색하여 로드합니다.
   - 파일명 또는 파일 수정일을 기반으로 데이터 기준일을 자동으로 추출하여 표시합니다.

2. **핵심 지표(Metric) 요약**
   - 병원 전체 장비 수량과 실제 Backup 관리 대상 장비 수량을 대시보드 상단에 직관적으로 표시합니다.
   - **Backup 완료 (통합 합계)** 및 **Backup 미완료 또는 불가** 항목을 대분류 및 소분류(PM, 보증, 임대 등)로 나누어 제공합니다.

3. **고해상도 백업 현황 비율 시각화 (Pie Chart)**
   - 백업 완료 비율과 미완료/불가 비율을 파이 차트로 시각화합니다.
   - 다크 모드와 라이트 모드 모두에서 뚜렷하게 식별 가능하도록 폰트 크기(약 20% 확대)와 굵기를 강화한 최적화된 가독성을 제공합니다.

4. **다양한 테마(다크/라이트 모드) 완벽 지원**
   - Streamlit의 시스템 테마 설정에 유연하게 대응하여 다크 모드에서도 텍스트와 레이블이 누락되지 않고 선명하게 표시됩니다.

5. **다각도 검색 및 상세 필터링**
   - **검색:** 장비명 또는 관리번호를 통한 실시간 키워드 검색
   - **사용부서 필터:** 특정 부서별 의료기기 백업 현황 단독 조회 (특정 제외 부서 필터링 자동 적용)
   - **백업 세부 유형 필터:** 완료, 미완료, PM, 보증, 임대 등 세부 관리대상 유형별 필터링

6. **상세 데이터 테이블 출력**
   - 필터링된 조건에 맞는 장비 목록을 표 형태로 제공하여 현황을 세부적으로 검토할 수 있습니다.
